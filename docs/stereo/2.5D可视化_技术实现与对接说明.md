## 一、技术总览

### 1.1 管线

```
D435i 深度图 (848×480, mono16 mm)
    │
    ▼
┌──────────────────────────────┐
│ stereo_terrain_node           │
│                               │
│  depth_to_3d()                │  深度(mm) → 相机3D (xc,yc,zc)
│       ↓                       │
│  camera_to_ground()           │  相机坐标系 → 地面坐标系 (xg,yg,zg)
│       ↓                       │
│  points_to_grid()             │  3D点云 → 80×60高程栅格
│       ↓                       │
│  grid_to_slope()              │  高程栅格 → 坡度 + 地形成本
│       ↓                       │
│  _grid_to_mesh()              │  高程栅格 → 三角形Mesh (Marker)
│                               │
└──────────────┬───────────────┘
               │
       ┌───────┼───────┐
       ▼       ▼       ▼
  /local_terrain  /terrain_cost  /terrain_mesh
  (2D热力图)      (导航用)       (2.5D可视化)
```

### 1.2 核心技术

| 环节 | 用到的技术 | 依赖 |
|:--|:--|:--|
| 深度→3D | 针孔相机模型 `X = (u-cx)×Z/fx` | NumPy |
| 坐标系变换 | 旋转矩阵 R(俯仰角) | 数学 |
| 点云→栅格 | `np.maximum.at` 聚合 | NumPy |
| 栅格→Mesh | TRIANGLE_LIST Marker | `visualization_msgs` |
| 可视化 | RViz2 Marker 显示 | ROS2 自带 |

**关键设计原则：**
- **前向投影**——世界坐标建地形 → 相机投影 → 深度图。障碍物遮挡关系天然正确
- **全 NumPy**——无大库依赖（grid_map、Open3D），真机一键部署

## 三、重点参数速查表

**所有参数在 `config/stereo_terrain.yaml`，改完重启 launch 即可，无需重编译。**

### 3.1 相机安装位姿（真机必调）

| 参数 | 默认值 | 含义 | 调参指南 |
|:--|:--|:--|:--|
| `cam_height` | 0.35 | 相机离地高度 (m) | 用卷尺量 D435i 镜头到地面距离，填入实际值 |
| `cam_pitch_deg` | 0.0 | 俯仰角 (°)，正=下倾 | 水平安装=0，下倾=正值。**错的后果：地面被算成斜坡或消失** |

> ⚠️ 这俩是所有后续运算的基石。装错 5cm 或 5°，整个高程图都会偏移。

### 3.2 栅格范围

| 参数 | 默认值 | 含义 | 调参指南 |
|:--|:--|:--|:--|
| `grid_resolution` | 0.05 | 每格 5cm | 0.10=粗略但快，0.03=精细但计算量大 |
| `grid_length_m` | 4.0 | 前方覆盖 (m) | Go2 0.3m/步，4m=13步前瞻 |
| `grid_width_m` | 3.0 | 左右覆盖 (m) | ±1.5m 够 Go2 体宽 0.7m |

### 3.3 深度过滤（决定哪些像素参与计算）

| 参数 | 默认值 | 含义 | 调参指南 |
|:--|:--|:--|:--|
| `depth_min` | 0.5 | 最近距离 (m) | 真机上设 0.3~0.5，**过滤 Go2 自己的腿**。模拟测试设 0.1 |
| `depth_max` | 6.0 | 最远距离 (m) | D435i >6m 精度快速下降，没必要保留 |

> ⚠️ `depth_min`/`depth_max` 过滤的是**地面前方距离 yg**，不是相机轴向 Zc。下倾相机时两者差异大。

### 3.4 高程过滤（决定地形高低的可见范围）

| 参数 | 默认值 | 含义 | 调参指南 |
|:--|:--|:--|:--|
| `z_min` | -0.02 | 最低高程 (m) | **必须是负值**。0m 是地面，设为 0.005 会把地面当噪声过滤。负值允许 D435i 2cm 精度误差 |
| `z_max` | 0.40 | 最高高程 (m) | 超过此值的物体=不可逾越障碍。同时也控制颜色映射上限 |

> ⚠️ `z_max` 同时影响两部分：
> 1. 过滤 — `zg > z_max` 的点直接丢弃
> 2. **颜色映射** — `z_max` 对应红色，`z_min` 对应蓝色，中间的障碍物颜色取决于 `(zg - z_min) / (z_max - z_min)`
>
> 如果全图都是一个颜色，先怀疑 `z_max` 设太大或障碍物高程太小。

### 3.5 发布频率

| 参数 | 默认值 | 调参指南 |
|:--|:--|:--|
| `publish_rate_hz` | 5.0 | Jetson 上 5Hz 无压力。Mesh 每帧 ~0.8MB，太高影响网络带宽 |
| `aggregation` | max | "max"=每格取最高点（推荐，障碍物不丢失），"mean"=平均 |

## 四、坐标变换公式（核心）

相机到地面的旋转矩阵（俯仰角 θ）：

```
R_c2w = [[1,   0,      0  ],
         [0,  -sinθ,  cosθ],
         [0,  -cosθ, -sinθ]]

xg = xc                          ← 左右不变
yg = -sinθ·yc + cosθ·zc          ← 地面前方距离
zg = H - cosθ·yc - sinθ·zc       ← 高程 (0=地面)
```

## 六、真机对接检查清单

### 前置

```bash

ros2 topic list | grep -E "camera.*depth.*image"
```

## 七、已知限制

| 限制 | 影响 | 缓解 |
|:--|:--|:--|
| 水平相机盲区 | pitch=0 时相机最近可见地面 ~0.6m，脚下看不到 | 加一点下倾角 (5-10°) |
| 无 SLAM 累积 | 每帧是独立快照，不拼成大地图 | 未来接 SLAM |
| `aggregation='max'` 夸大障碍 | 单根草可能被当障碍物 | 用 mean 或下采样 |
| 单帧数据量 | 848×480 → 200k 点 → 80×60 栅格，有效格 40-70% | 覆盖足够导航 |
