## 一、问题分析

之前两个节点往同一个话题发：

```
simulated_input_node  →  /terrain_cost  (公式生成的假值)
stereo_terrain_node   →  /terrain_cost  (D435i 实时算的真值)
                              ↑
                      safety_supervisor 订阅这里
                              ↑
                    两个发布者冲突！
```

解决思路：加一个 `use_stereo` 开关，打开时：
1. `simulated_input_node` 不发假 terrain（新增 `publish_terrain=false` 参数）
2. `stereo_terrain_node` 启动，接管 `/terrain_cost`

## 二、具体改动

### 改 1: `simulated_input_node.py`

新增参数 `publish_terrain`，设为 false 时跳过 terrain_cost 发布：

```python
# __init__ 新增:
self.declare_parameter('publish_terrain', True)
...
self._publish_terrain = self.get_parameter('publish_terrain').value

# _on_timer 中把 terrain 发布包在条件里:
if self._publish_terrain:
    terrain = Float32()
    terrain.data = float(self._scenario.terrain_cost(self._time))
    self._terrain_pub.publish(terrain)
```

> 默认 `True`（兼容仿真模式），仅当 launch 传入 `publish_terrain:=false` 时关闭。

### 改 2: `closed_loop_demo.launch.py`

新增 `use_stereo` 启动参数 + 条件启动 stereo_terrain_node：

```python
# 新增声明:
DeclareLaunchArgument(
    'use_stereo', default_value='false',
    description='设为 true 启动 stereo_terrain_node',
),

# simulated_input_node: 两个条件实例
#   当 use_stereo=true 时，传 publish_terrain:=false
#   当 use_stereo=false 时，用默认值（发 terrain）
Node(..., parameters=[{'scenario': scenario, 'publish_terrain': False}],
     condition=IfCondition(use_stereo)),
Node(..., parameters=[{'scenario': scenario}],
     condition=UnlessCondition(use_stereo)),

# 新增节点:
Node(
    package='dog_nav_step56',
    executable='stereo_terrain_node',
    name='stereo_terrain_node',
    output='screen',
    parameters=[stereo_params],
    condition=IfCondition(use_stereo),
),
```

> 用 `IfCondition`/`UnlessCondition` 实现二选一：stereo 模式下用不发的 simulated_input，普通模式下用发的。

### 为什么用两个 Node 声明而不是一个带条件参数？

ROS2 launch 的参数是声明时计算的，不能在运行中"如果 A 则 B 否则 C"。用两个 Node + 条件是最干净的做法，不会互相冲突（只有一个会被启动）。

|:--|:--|

## 二、真机完整测试流程

### 预备（只需一次）

**Go2 SSH：**
```bash
ros2 topic echo /camera/depth/image_rect_raw --once | head -1
# 没输出 → sudo apt install ros-humble-realsense2-camera
```

**VM：**
```bash
cd ~/Daohang
source /opt/ros/humble/setup.bash
source src/unitree_ros2/cyclonedds_ws/install/setup.bash
colcon build --packages-select dog_nav_step56
source install/setup.bash
```

### 真机 4 步

**第 1 步：物理连接**

```
电脑以太网口 ←── 网线 ──→ Go2 背部网口
Windows 设: 192.168.123.99 / 255.255.255.0 / 网关留空
```

**第 2 步：VM 网口 + DDS（每次开机）**

```bash
sudo ip addr add 192.168.123.100/24 dev ens38

export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
export CYCLONEDDS_URI='<CycloneDDS><Domain><General><Interfaces><NetworkInterface address="192.168.123.100"/></Interfaces></General></Domain></CycloneDDS>'

ping -c 2 192.168.123.18   # 确认通
```

**第 3 步：验证 Go2 就绪**

```bash
# Go2 SSH:
ros2 topic list | grep sport
# 需看到 /lf/sportmodestate
```

**第 4 步：启动（遥控器放手边）**

```bash
# VM：
source ~/Daohang/install/setup.bash
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
export CYCLONEDDS_URI='<CycloneDDS><Domain><General><Interfaces><NetworkInterface address="192.168.123.100"/></Interfaces></General></Domain></CycloneDDS>'

ros2 launch dog_nav_step56 closed_loop_demo.launch.py \
    use_bridge:=true use_stereo:=true scenario:=test_forward
```

**同时监控（另开终端）：**

```bash
# VM 终端2: 看 2.5D 输出
ros2 topic echo /terrain_cost
# 预期: 20(平坦) ~ >100(有障碍)

# Go2 SSH: 看 Go2 收到的指令
ros2 topic echo /api/sport/request
# 预期看到 Move(1008) / GaitSwitch 等
```

## 三、数据流

```
Go2 Jetson:                                   VM:

D435i ──→ /camera/depth/... ──(DDS)──→ stereo_terrain_node
                                                 ↓
                                          /terrain_cost ──→ safety_supervisor
                                                  ↑            ↓
simulated_input ──→ /global_path ──→ local_controller → motion_adapter
                   /odometry/filtered                        ↓
                   /imu/data                    unitree_bridge
             (不发 terrain)                            ↓
                                                ←── DDS ──→ Go2
                                             /api/sport/request
                                          Move/Damp/Gait/Speed
```
