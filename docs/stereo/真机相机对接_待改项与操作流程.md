## 二、需要改的代码（2 处）

### 改 1: `simulated_input_node.py` — 加地形开关参数

加一个参数 `publish_terrain`，设为 false 就不再发 `/terrain_cost`：

```python
# __init__ 里新增:
self.declare_parameter('publish_terrain', True)
self._publish_terrain = self.get_parameter('publish_terrain').value

# _on_timer 里改 terrain 发布:
if self._publish_terrain:
    self._terrain_pub.publish(terrain)
```

### 改 2: `closed_loop_demo.launch.py` — 加 `use_stereo` 参数

```python
# 新增声明:
DeclareLaunchArgument(
    'use_stereo', default_value='false',
    description='真机模式时启动 stereo_terrain_node (替代假 terrain)',
),

# simulated_input_node 加条件参数:
Node(
    ...
    parameters=[{
        'scenario': scenario,
        'publish_terrain': 'false',   # 新参数
    }],
    condition=IfCondition(use_stereo),  # 新: 仅 stereo 模式下设为 false
),

# 新增节点:
Node(
    package='dog_nav_step56',
    executable='stereo_terrain_node',
    name='stereo_terrain_node',
    output='screen',
    condition=IfCondition(use_stereo),
    parameters=[PathJoinSubstitution([
        FindPackageShare('dog_nav_step56'),
        'config',
        'stereo_terrain.yaml',
    ])],
),
```

> 实际上更简单：simulated_input 的 `publish_terrain` 改法和 `use_stereo` 条件判断的写法需要根据实际 launch 语法微调。核心逻辑就上面这些。

## 三、改完后的运行

### 3.1 启动方式

```bash
# 仿真模式 (不变):
ros2 launch dog_nav_step56 closed_loop_demo.launch.py scenario:=test_forward

# 真机桥接 + 假地形 (不变):
ros2 launch dog_nav_step56 closed_loop_demo.launch.py \
    use_bridge:=true scenario:=test_forward

# ★ 真机桥接 + 真实相机 2.5D 地形 (新增):
export RMW_IMPLEMENTATION=rmw_cyclonedds_cpp
export CYCLONEDDS_URI='<CycloneDDS><Domain><General><Interfaces><NetworkInterface address="192.168.123.100"/></Interfaces></General></Domain></CycloneDDS>'
ros2 launch dog_nav_step56 closed_loop_demo.launch.py \
    use_bridge:=true use_stereo:=true scenario:=test_forward
```

### 3.2 相机→2.5D→导航 数据流

```
Go2 Jetson:                                  VM:
                                           
D435i                                       stereo_terrain_node
  ↓                                                   ↓
realsense2_camera  ──→ /camera/depth/...  ──→  深度→3D→栅格→坡度
  (Go2 预装)                                    ↓
                                          /local_terrain (可视化)
                                          /terrain_cost (给导航)
                                                   ↓
                 Go2 硬件  ←── DDS ←─── unitree_bridge ← motion_adapter
                 ↑                                    ↑
            收到 Move/Damp/...              safety_supervisor 读 terrain_cost
```

### 3.3 验证步骤

```bash
# 终端1: 启动真机+相机
ros2 launch dog_nav_step56 closed_loop_demo.launch.py \
    use_bridge:=true use_stereo:=true scenario:=test_forward

# 终端2: 看 2.5D 输出
ros2 topic echo /terrain_cost
# 预期: 20 (平坦地面) ~ 170 (有障碍)

# 终端3 (Go2 SSH): 看 Go2 收到的指令
ros2 topic echo /api/sport/request
```
