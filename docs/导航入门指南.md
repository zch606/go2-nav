# 机器狗导航入门指南 — 从传统方案到本项目实现

> 面向：导航零基础的新手
> 日期：2026-05-31

---

## 一、一句话概括导航

> 给机器人**一张地图** + **一个位置** + **一个目标**，让它算出**怎么走过去**，途中**避开障碍**。

用自动驾驶类比：

| 汽车 | 机器狗 |
|:--|:--|
| GPS 定位 | 里程计 + IMU → 推算位置 |
| 高精地图 | 2.5D 地形图（哪里能踩哪里不能踩） |
| 车载摄像头/雷达 | D435i 深度相机 |
| 导航引擎 | Pure Pursuit / Nav2 |
| 方向盘/油门 | 动作序列 → Go2 API |

## 二、传统导航三层架构（每个机器人都这么分）

```
┌──────────────────────────────────┐
│  感知层  (Sense)                  │
│  摄像头/激光雷达/IMU → 环境模型     │
├──────────────────────────────────┤
│  规划层  (Plan)                   │
│  全局规划(去哪) + 局部规划(怎么走)  │
├──────────────────────────────────┤
│  控制层  (Act)                    │
│  速度指令 → 电机/关节              │
└──────────────────────────────────┘
```

### 2.1 感知层 — 用什么看世界？

| 传感器 | 产出 | 我们的项目用了吗 |
|:--|:--|:--|
| **双目/RGBD 相机** (D435i) | 深度图 → 3D 点云 → 2.5D 高程栅格 | ✅ `stereo_terrain_node` |
| IMU (惯性测量单元) | 角速度 + 加速度 → 姿态角(roll/pitch) | ✅ 真机直接拿 Go2 的 |
| 里程计 (Odometry) | 轮速/视觉推算 → 机器人当前位置 | ✅ 真机 Go2 / 仿真公式 |
| 激光雷达 (LiDAR) | 360° 2D/3D 障碍物距离 | ❌ Go2 没装 |

### 2.2 规划层 — 核心算法

传统方案分为两级：

**全局规划 (Global Planner):**
> 回答"走哪条路从 A 到 B"

| 算法 | 原理 | 适用场景 |
|:--|:--|:--|
| **A\*** | 网格寻路，最小化路径代价 | 室内/结构化环境 |
| **Dijkstra** | 类似 A\* 但没有启发式 | 任意地形 |
| **RRT/RRT\*** | 随机采样连接空间 | 高维/复杂约束 |
| **Nav2 SmacPlanner** | A\* 增强版，带运动学约束 | 真机首选 |

**局部规划 (Local Planner):**
> 回答"下一步踏哪里，多快，怎么转"

| 算法 | 原理 |
|:--|:--|
| **Pure Pursuit** | 在路径前方选一个预瞄点，转弯追它 |
| **DWA (动态窗口法)** | 模拟所有可能速度，选得分最高的 |
| **MPC (模型预测控制)** | 优化未来 N 步轨迹 |
| **Regulated Pure Pursuit** | Pure Pursuit + 碰撞检测 + 曲率限速 |

**我们项目用的是:** Pure Pursuit (`local_controller_node.py`)

### 2.3 控制层 — 指令到动作

| 输出 | 含义 |
|:--|:--|
| `vx` | 前进速度 (m/s) |
| `vy` | 横向速度 (m/s, Go2 一般不用) |
| `wz` | 旋转角速度 (rad/s) |

我们的 `motion_adapter_node` 把 `cmd_vel` 转成 Go2 专用格式：`vx, wz, gait(步态), body_height(身高), speed_level(速度档)`。

## 三、本项目目前的导航方案

```
              D435i          Go2 IMU/里程计
                │                  │
        ┌───────▼───────┐  ┌──────▼──────┐
        │ stereo_terrain │  │ Go2 硬件     │
        │ 深度→2.5D栅格   │  │ odom        │
        └───────┬───────┘  └──────┬──────┘
                │                 │
        ┌───────▼─────────────────▼──────┐
        │         safety_supervisor      │
        │   terrain_cost + 姿态 → 安全级别 │
        └───────────────┬───────────────┘
                        │
        ┌───────────────▼───────────────┐
        │        local_controller       │
        │   Pure Pursuit → cmd_vel      │
        │   前瞻1.5m, 10Hz              │
        └───────────────┬───────────────┘
                        │
        ┌───────────────▼───────────────┐
        │       motion_adapter          │
        │   cmd_vel → DogMotion         │
        │   (vx,wz,gait,height,speed)   │
        └───────────────┬───────────────┘
                        │
        ┌───────────────▼───────────────┐
        │        unitree_bridge         │
        │   DogMotion → Go2 API         │
        │   Move/Damp/Gait/SpeedLevel   │
        └───────────────────────────────┘
```

### 当前用到的最简方案

| 层 | 我们用的 | 成熟的替代方案 |
|:--|:--|:--|
| 全局规划 | 无（仿真用预设路径） | Nav2 SmacPlanner |
| 局部规划 | Pure Pursuit | Nav2 Regulated PP / DWA |
| 局部避障 | 无（只靠地形代价降速） | Nav2 local_costmap + obstacle layer |
| 定位 | Go2 原生 | robot_localization EKF |
| 地形 | D435i → 2.5D 栅格 | grid_map / elevation_mapping |

> **我们的方案是"最小可行版本"**，后续可以逐步把 Nav2 的标准模块替换进来。

## 四、新手入门路线图

### 第 1 步：理解 ROS2 基础（1-2 天）

- Topic / Service / Action 的概念
- `rclpy` 写节点：发布者 + 订阅者
- launch 文件怎么写

**资料：**

- [ROS2 Humble 官方教程](https://docs.ros.org/en/humble/Tutorials.html)
- 必做：`Writing a simple publisher and subscriber (Python)`

### 第 2 步：理解坐标系和 TF2（半天）

- `map → odom → base_link → sensor_frame` 是什么
- TF2 的作用：把所有传感器数据对齐到同一个坐标系

**资料：**

- [ROS2 TF2 教程](https://docs.ros.org/en/humble/Tutorials/Intermediate/Tf2/Tf2-Main.html)

### 第 3 步：理解导航基本概念（1 天）

必懂概念：
- **Costmap（代价地图）：** 把世界画成格子，每个格子有通行代价（0=可走，255=墙）
- **Global Planner：** 在 costmap 上找全局路径
- **Local Planner：** 跟踪全局路径，同时避开动态障碍
- **Pure Pursuit：** 最简单的局部规划——在路径前方选一个点，追它

**资料：**
- [Nav2 概念文档](https://docs.nav2.org/concepts/index.html)
- 只看 "Costmap2D" 和 "Planners" 两节就行

### 第 4 步：跑一遍我们项目（1 天）

```bash
# 仿真模式
ros2 launch dog_nav_step56 closed_loop_demo.launch.py scenario:=test_forward

# 然后逐个看每个节点的输出:
ros2 topic echo /global_path     # 路径长什么样
ros2 topic echo /odometry/filtered  # 机器人在哪
ros2 topic echo /cmd_vel         # Pure Pursuit 输出什么速度
ros2 topic echo /motion_command  # 最终发给 Go2 的指令
```

### 第 5 步（进阶）：接入 Nav2

把我们的 Pure Pursuit 换成 Nav2 的 Regulated Pure Pursuit 或 DWA，接入真正的全局规划器。

## 六、常见术语速查

| 术语 | 一句话解释 |
|:--|:--|
| **costmap** | 带代价的栅格地图，越红越不能走 |
| **global_planner** | 在地图上找一条从 A 到 B 的全局路径 |
| **local_planner** | 沿着全局路径走，同时躲开突然出现的障碍 |
| **Pure Pursuit** | 最简单的 local planner：前方选个点，追过去 |
| **DWA** | 更聪明的 local planner：模拟几十条轨迹，选最好的 |
| **EKF** | 卡尔曼滤波，融合多个传感器数据算出最可信的位置 |
| **terrain_cost** | 0~255 的地形成本，`20=可跑` `150=小心` `240=不能走` |
| **BEV** | Bird's Eye View 鸟瞰图，从上往下看的2D投影 |
| **DogMotion** | 我们定义的 Go2 专用指令：vx, wz, 步态, 身高 |
