# 步骤 5-6 快速测试清单

## 1. 一次性准备
```bash
source /opt/ros/humble/setup.bash
source /root/ws/install/setup.bash
```

如果还没构建：
```bash
cd /root/ws
colcon build --base-paths src --packages-select dog_nav_interfaces dog_nav_step56
source install/setup.bash
```

## 2. 默认跑法
```bash
ros2 launch dog_nav_step56 step56_test.launch.py
```

默认会把测试记录写到：
```bash
/root/ws/step56_test_trace.jsonl
```

## 3. 风险测试跑法
```bash
ros2 launch dog_nav_step56 step56_test.launch.py simulate_tilt:=true terrain_cost:=140.0
```

## 4. 调参跑法
```bash
ros2 launch dog_nav_step56 step56_test.launch.py path_length:=16 path_spacing:=0.4 publish_rate_hz:=15.0 controller_rate_hz:=25.0
```

控制器常用参数也可以一起调：
```bash
ros2 launch dog_nav_step56 step56_test.launch.py \
	min_lookahead_distance:=0.40 max_lookahead_distance:=1.00 \
	max_linear_speed:=0.50 max_angular_speed:=1.30 \
	turn_gain:=2.40 speed_gain:=0.80 \
	curvature_speed_scale:=0.65 heading_slowdown_angle:=0.70 heading_stop_angle:=1.25
```

参数含义：
- `path_length`：模拟路径点数
- `path_spacing`：路径点间距
- `publish_rate_hz`：模拟输入发布频率
- `controller_rate_hz`：局部控制器刷新频率
- `min_lookahead_distance` / `max_lookahead_distance`：前瞻距离上下限
- `max_linear_speed` / `max_angular_speed`：速度上限
- `turn_gain` / `speed_gain`：转向和前进增益
- `curvature_speed_scale`：曲率越大时的降速强度
- `heading_slowdown_angle` / `heading_stop_angle`：大转角时的减速和停转阈值

## 5. 看什么话题
- `/global_path`
- `/odometry/filtered`
- `/imu/data`
- `/terrain_cost`
- `/cmd_vel`
- `/safety_state`
- `/motion_command`

## 6. 正常结果
- `/cmd_vel` 持续输出速度
- `/motion_command` 跟着 `/cmd_vel` 变化
- `terrain_cost` 或姿态升高时安全状态会降级
- 高风险时会进入 `STOP`，动作速度归零

## 7. 快速抽查
```bash
ros2 topic echo --once /cmd_vel
ros2 topic echo --once /safety_state
ros2 topic echo --once /motion_command
```

## 8. 结论
- 先用模拟数据跑闭环
- 真机对接后面再接

## 9. 测试记录文件
- 每次启动测试都会追加写入 JSONL
- 每一行对应一个话题事件，包含时间戳、事件类型和关键字段
- 文件里会记录 `/global_path`、`/odometry/filtered`、`/imu/data`、`/terrain_cost`、`/cmd_vel`、`/safety_state`、`/motion_command`
- 默认文件路径：`/root/ws/step56_test_trace.jsonl`
- 查看最近记录：`tail -n 20 /root/ws/step56_test_trace.jsonl`
- 统计行数：`wc -l /root/ws/step56_test_trace.jsonl`
